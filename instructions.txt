This project is a lightweight display interface for a Raspberry Pi running Volumio. Instead of using Chromium, X11, Wayland, SDL, Qt, or the official touch display plugin, it writes directly to the Linux framebuffer at /dev/fb0.

The goal is simple: show useful Volumio playback information with very low overhead.

The display shows:

- Large local clock
- Animated blinking colon as a basic heartbeat
- Current date
- Local IP address
- Current song title (only when playing something)
- Current artist (only when playing something)
- Playback progress bar
- Elapsed and total track time
- Clean idle mode when nothing is playing
- Clock returns to large size when not playing something

The clock does not get time from Volumio. It reads the Linux system clock using time(NULL), converts it with localtime_r(), and formats it with strftime(). If the OS clock is synced by NTP, the display follows automatically.

Playback data comes from the local Volumio API:

http://127.0.0.1:3000/api/v1/getState

The program polls that API, parses the JSON response with json-c, and updates the display based on whether Volumio is playing, paused, stopped, or unavailable.

The graphics are rendered in C using FreeType for fonts, then converted to RGB565 and copied directly into the framebuffer. This keeps the project lean and avoids a browser-based UI stack.

The install process is:

1. Enable SSH on Volumio.
2. Install framebuffer overlay.
3. Copy the compiled binary to /home/volumio/.
4. Install it to /usr/local/bin/volumio_clock_fb.
5. Make it executable.
6. Create a systemd service.
7. Enable and start the service.

The service runs as root because it needs direct framebuffer access.

-- instructions --

# enable ssh:
http://YOUR-VOLUMIO-IP/dev

# login to your volumio:
ssh volumio@volumio.local

# create overlay directory:
sudo mkdir -p /boot/overlays

# download GoodTFT 3.5" framebuffer overlay:
sudo curl -L https://github.com/goodtft/LCD-show/raw/master/usr/tft35a-overlay.dtb -o /boot/overlays/tft35a.dtbo

# create min framebuffer config:
sudo nano /boot/userconfig.txt

# GoodTFT 3.5 inch SPI LCD framebuffer
dtparam=spi=on
dtoverlay=tft35a:rotate=270

# upload the binary to:
/home/volumio/volumio_clock_fb

# copy the binary:
sudo cp /home/volumio/volumio_clock_fb /usr/local/bin/volumio_clock_fb

# allow it to run:
sudo chmod +x /usr/local/bin/volumio_clock_fb

# create the service:
sudo nano /etc/systemd/system/volumio-clock.service

[Unit]
Description=Volumio framebuffer clock
After=local-fs.target systemd-udev-settle.service network-online.target time-sync.target volumio.service
Wants=systemd-udev-settle.service network-online.target time-sync.target

[Service]
Type=simple
ExecStartPre=/bin/sh -c 'for i in $(seq 1 30); do [ -e /dev/fb0 ] && exit 0; sleep 1; done; echo "/dev/fb0 missing"; exit 1'
ExecStart=/usr/local/bin/volumio_clock_fb
Restart=always
RestartSec=2
User=root

[Install]
WantedBy=multi-user.target

# enable the service and reboot:
sudo systemctl daemon-reload
sudo systemctl enable volumio-clock.service
reboot
